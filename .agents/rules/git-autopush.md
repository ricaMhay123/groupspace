# Auto-push to GitHub

After **every change** made to any file in this project, always:

1. Stage the changed files with `git add`
2. Commit with a clear, descriptive commit message
3. Push to GitHub with `git push`

Do this **automatically** after every edit — never wait to be asked.

> **Note:** Use semicolons (`;`) instead of `&&` when chaining git commands in PowerShell.
> Example: `git add .; git commit -m "message"; git push`
